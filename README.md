# 17 November 2026 in one image

A drawn news poster summing up Tuesday 17 November 2026's world news, built
for the make.fun competition
[news-image-20261117](https://make.fun/bounty/news-image-20261117).

The poster names the day and covers six stories reported that day, across
regions and fields: Ukraine's strike on the Kerch Bridge, Iranian drones
targeting a U.S. base in Bahrain and mines near Hormuz, the Houthi advance
toward Aden, Western allies urging Israel to open Gaza's crossings, Trump's
Manila visit for the ASEAN summit, and Bitcoin below $65,000 ahead of Nvidia
earnings. Every claim in the image is attributed as reported.

`main.ts` (Node 22, standard library only) copies `entry.png` to the output
directory. The image is 1024 by 1024 pixels and under 1 MiB.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
